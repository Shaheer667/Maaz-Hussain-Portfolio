# Maaz Hussain — Video Editing Portfolio

This project intentionally keeps the same simple structure and `data/videos.js` format as the Kanchan portfolio source.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Updating portfolio videos

Your portfolio content lives in:

```text
data/videos.js
```

The data structure, exports, category slugs, and category-page filtering are unchanged from the Kanchan source. You can therefore replace this file with the Kanchan project's `data/videos.js` directly when you want the same portfolio entries.

## Files you will most likely update later

- `data/videos.js` — portfolio videos and categories
- `components/Contact.jsx` — replace `your@email.com` with Maaz's real email
- `components/Footer.jsx` — social links are intentionally still the current Kanchan links for now
- `public/maaz.png` — replace with Maaz's preferred hero image if desired
- `public/maaz-about.png` — replace with Maaz's about image if desired

## Design palette

The site uses a cinematic warm-dark palette: charcoal black, ember orange, copper, warm gold, and warm white.
